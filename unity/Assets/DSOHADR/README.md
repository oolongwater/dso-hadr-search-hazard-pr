# DSO HADR Unity Workspace

This directory is reserved for DSO-specific Unity code, tests, materials, VFX, prefabs, and test scenes.

The current contents are scaffolding only. No hazard events, Unity actions, prefabs, scenes, C# classes, or simulator behavior are implemented by this setup.

Unity owns realized simulator state and should expose authoritative hazard metadata to Python. Visual effects should not be treated as authoritative graph state.
